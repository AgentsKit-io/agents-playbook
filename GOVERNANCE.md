# Governance

Agents Playbook is maintained in the open by the AgentsKit community. Emerson
Braun is the current project lead and final decision-maker while the maintainer
group grows.

## Decisions

Routine changes use pull requests and the review process in
[CONTRIBUTING.md](./CONTRIBUTING.md). Changes that alter project direction,
licensing, governance, or public contracts require explicit maintainer approval
and a written rationale in the pull request or a linked issue.

Maintainers evaluate proposals for demonstrated failure modes, portability
across tools, compatibility with the existing corpus, and enforceability. When
consensus is not possible, the project lead makes the decision and records the
reason publicly.

## Maintainers

Maintainers review contributions, manage releases, enforce community standards,
and handle security reports. New maintainers are nominated by an existing
maintainer based on sustained, constructive contributions and are added with the
approval of the project lead.

Inactive maintainers may step down or be moved to emeritus status after a public
discussion. A maintainer may be removed for repeated violations of the Code of
Conduct or actions that put users or the project at risk.

## Changes to governance

Governance changes are proposed by pull request. They require approval from the
project lead and at least one additional reviewer when another active maintainer
is available.
