# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest published
version of `@agentskit/playbook`. Older package versions may not receive fixes.

## Reporting a vulnerability

Use
[GitHub private vulnerability reporting](https://github.com/AgentsKit-io/agents-playbook/security/advisories/new)
to report a suspected vulnerability. Do not open a public issue, discussion, or
pull request for an undisclosed vulnerability.

Include the affected component and version, reproduction steps, impact, and any
suggested mitigation. Remove secrets, personal data, and confidential customer
information from the report.

The maintainers aim to acknowledge reports within three business days and
provide an initial assessment within seven business days. Timelines for a fix
and coordinated disclosure depend on severity and complexity. We will credit
reporters who request attribution.

If private vulnerability reporting is unavailable, contact the repository owner
through the contact method listed on the
[AgentsKit organization profile](https://github.com/AgentsKit-io).
